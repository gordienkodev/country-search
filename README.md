# country-search

## Запуск

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. Изменения TypeScript компилируются автоматически;
после изменения HTML или CSS перезапустите `npm run dev`.

## Сборка

```sh
npm run build
npm run serve
```

Готовое приложение находится в `dist`. Для GitHub Pages публикуется содержимое этой папки.
